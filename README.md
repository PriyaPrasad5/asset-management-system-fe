# React + Vite
================
### Overview
This is a simple React application built with Vite, a fast and lightweight development server.
### Features
* Fast development server with hot reloading
* Lightweight and efficient build process
* Supports ES modules and modern JavaScript features
### Getting Started
1. Clone the repository: `git clone https://github.com/PriyaPrasad5/asset-management-system-fe.git`
2. Install dependencies: `npm install` or `yarn install`
3. Start the development server: `npm run dev` or `yarn dev`
4. Open your web browser and navigate to `http://localhost:5173`
